# SkillMatch

## Descripción del proyecto SkillMatch
SkillMatch es una plataforma web orientada al intercambio no monetario de conocimientos y habilidades entre personas que desean aprender y enseñar dentro de una comunidad. El sistema permite registrar usuarios, administrar perfiles, publicar habilidades ofrecidas y requeridas, buscar coincidencias, enviar solicitudes de conexión, establecer comunicación privada y calificar las experiencias de intercambio. Además, incluye funciones administrativas para gestionar usuarios, administrar roles, gestionar categorías y habilidades, moderar cuentas y gestionar políticas de tratamiento de datos.


## Tecnologías previstas

- Node.js
- Express
- JavaScript
- MySQL
